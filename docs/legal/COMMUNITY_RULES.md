# VoidCriptUI — Community & Forum Conduct Rules

Do not post harassment, hate, spam, phishing, malware, credential theft, malicious links, doxxing, impersonation, ban-evasion instructions, fake security claims, or intentionally disruptive content.

Issues should include reproducible details where possible. Questions should remain technically relevant. Suggestions should explain the user problem or use case rather than demanding implementation.

Moderators may label, edit, lock, merge, hide or remove content. Temporary or permanent account restrictions may be applied for repeated or severe violations. Moderation actions should be recorded in the audit trail when performed by privileged staff.

Security vulnerabilities should use the responsible-disclosure channel rather than public exploitation instructions.
